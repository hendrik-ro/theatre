Theatre
=======

A browser-based app to track watched movies.

## Features

- Tracks watched movies

## Tech Stack

- **Client**: [vite.js](https://vitejs.dev/)
- **Server**: [express.js](https://expressjs.com/)
- **Database**: [PostgreSQL](https://www.postgresql.org/)
